# Assignment 1 – OPPO Find X9 Ultra

## Project Description

I started by setting up the project with `index.html`, `order.html`, the `assets` folder, and `css/styles.css`.

I then created the structure of `index.html` and continued with `order.html`. Initially, I linked `styles.css` to both HTML files. Later, I split the CSS into separate files to make the code easier to maintain.

The website consists of a product page for the OPPO Find X9 Ultra and an order page with a form for ordering the product.

## Images

The images of the OPPO Find X9 Ultra were sourced from OPPO’s website:

https://www.oppo.com/no/smartphones/series-find-x/find-x9-ultra/

The images are stored locally in `assets/images`.

## CSS

I used Flexbox for the navigation menu and CSS Grid to display the product specifications.

The CSS is organised into separate files:

- `reset.css`: resets default margins and padding and sets box-sizing.
- `variables.css`: defines shared variables for colours, spacing, font family, and font sizes.
- `styles.css`: contains general styles and styles for the product section and order form.
- `navbar.css`: contains navigation styles.
- `footer.css`: contains footer styles.

I used a consistent spacing system based on multiples of 4px and CSS variables with rem units for font sizes. Google Fonts is loaded using a `<link>` tag in both HTML files.

The website uses media queries to adapt the layout to smaller screens.

## BEM

I used BEM naming conventions for the navigation menu and product section, including:

`navbar__logo`, `navbar__link`, `product__image`, `product__video`, and `product__description`.
