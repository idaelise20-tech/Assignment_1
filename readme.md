# Assignment 1 – OPPO Find X9 Ultra

## Beskrivelse av prosjektet

Jeg startet med å lage oppsettet for prosjektet med `index.html`,
`order.html`, `assets`-mappen og `css/styles.css`.

Deretter satte jeg opp strukturen i `index.html` og fortsatte med
`order.html`. Jeg koblet `styles.css` til begge HTML-filene.

Nettsiden består av en produktside for OPPO Find X9 Ultra og en
bestillingsside med skjema for bestilling av produktet.

## Bilder

Bildene av OPPO Find X9 Ultra er hentet fra OPPO sin nettside:

https://www.oppo.com/no/smartphones/series-find-x/find-x9-ultra/

Bildene er lagret lokalt i `assets/images`.

## CSS

Jeg har brukt Flexbox i navigasjonsmenyen og CSS Grid for å vise
produktspesifikasjonene.

Jeg har brukt CSS-variabler for blant annet farger, font og størrelse.
Nettsiden er også gjort responsiv med media query slik at layouten
tilpasser seg mindre skjermer.

## BEM

Jeg har brukt BEM-navngivning på blant annet navigasjonsmenyen og
produktseksjonen, for eksempel:

`navbar__logo`, `navbar__link`, `product__image`,
`product__video` og `product__description`.
